# dotfiles

My macOS and Linux development environment, built with Nix.

```sh
curl -fsSL https://raw.githubusercontent.com/Hiro-mackay/dotfiles/main/install.sh | sh
```

Then sign in to `claude` and `codex`. On macOS, also allow Hammerspoon and Warp under
Accessibility, open Docker Desktop and run `sbx login`, and import
`programs/bettertouchtool/Default.bttpreset` in BetterTouchTool.

Keep it current with `dotup`. Everything else is in the [cookbook](docs/cookbook.md).
